# Конфигурация инфраструктуры и стека "АвтоЛог"

## 1. Технический стек (Tech Stack)
*   **Framework:** Next.js (App Router) — для Fullstack разработки (Frontend + API).
*   **Language:** TypeScript — для типизации и предотвращения ошибок.
*   **Styling:** Tailwind CSS — для быстрой и адаптивной верстки.
*   **Database:** PostgreSQL — основная реляционная БД.
*   **ORM:** Prisma или Drizzle — для удобной работы с БД из TypeScript.
*   **Authentication:** NextAuth.js или Clerk (адаптировано под РФ) — вход через Google/Telegram.
*   **File Storage:** S3-совместимое хранилище (Yandex Object Storage).
*   **OCR Engine:** Yandex Vision OCR — для распознавания текста.
*   **LLM Processing:** YandexGPT API — для парсинга OCR-текста в структурированный JSON.

---

## 2. Процесс обработки данных (Data Pipeline)
1.  **Загрузка:** Пользователь загружает фото документа в S3.
2.  **OCR:** Вызов Yandex Vision, получение "сырого" текста.
3.  **Structured Parsing:** Передача текста в YandexGPT с системным промптом для извлечения сущностей (VIN, пробег, список работ, цены).
4.  **Validation:** Отображение JSON-данных пользователю для проверки и правки.
5.  **Storage:** Сохранение верифицированных данных в PostgreSQL.

---

## 3. Хостинг и Сервер (Yandex Cloud)
*Целевая конфигурация для запуска MVP:*

### Виртуальная машина (Compute Cloud)
*   **Платформа:** Intel Ice Lake (v3).
*   **vCPU:** 2 ядра.
*   **Гарантированная доля vCPU:** 20% (на старте).
*   **RAM:** 4 ГБ (рекомендуется для стабильной работы Docker + Next.js).
*   **Диск:** 30 ГБ (Network HDD).
*   **Публичный IP:** Да (Обязательно для привязки домена).
*   **ОС:** Ubuntu 24.04 LTS.

### Объектное хранилище (Object Storage / S3)
*   **Тип:** Стандартное.
*   **Объем:** 100 ГБ на старте.

### База данных (Managed Service for PostgreSQL)
*   *На этапе MVP:* Развернута прямо на виртуальной машине (Docker).
*   *На этапе Роста (>5000 юзеров):* Переход на Managed Service (2 CPU, 4GB RAM).
