# User Flow проекта "АвтоЛог"

## Сценарий 1: Регистрация и первое авто (Onboarding)
1. **Welcome Screen:** УТП (Ценностное предложение).
2. **Login/Signup:** Упрощенная регистрация.
3. **Add Car:** Ввод данных авто (Марка, Модель, Год, Пробег).
4. **Empty Dashboard:** Состояние "Машина добавлена, данных нет".

## Сценарий 2: Оцифровка чека (The Core Loop)
1. **Action:** Нажатие на кнопку "+" (Добавить запись).
2. **Source:** Выбор: Фото чека или загрузка файла.
3. **Processing:** OCR-распознавание данных (Дата, Сумма, Работы).
4. **Validation:** Экран проверки распознанных данных пользователем.
5. **Categorization:** Присвоение категории (ТО, Ремонт, Запчасти).
6. **Confirmation:** Сообщение об успешном сохранении.

## Сценарий 3: Управление и Аналитика
1. **History Feed:** Лента событий с поиском и фильтрами.
2. **Statistics:** Графики расходов (по месяцам/категориям).
3. **Maintenance Forecast:** Уведомление о предстоящих работах (на основе пробега).

## Сценарий 4: Подготовка к продаже (Export)
1. **Export Entry:** Кнопка "Сформировать отчет".
2. **Options:** Выбор периода и типов записей.
3. **Delivery:** Генерация PDF-отчета или публичной Web-ссылки.
4. **Sharing:** Кнопка "Поделиться" (WhatsApp, Telegram, Avito).
