# ТЗ на разработку сайта 
Концепция сайта - saas. Главная страница с УТП, Отзывами, Описанием продукта и преимуществами.

## Главная страница [ПОЧТИ ГОТОВО]
### [x] Header
Содержит:
1. логотип
2. Меню (Возможности, Как начать, Отзывы, Безопасность, FAQ)
3. Регистрация/вход

### [x] Hero
Контролируйте расходы и планируйте бюджет. Простой инструмент для контроля за тратами на автомобиль.
Primary button "Создать гараж бесплатно". Secondary button "Посмотреть демо".

### [x] Возможности (Features)
Всё для контроля автомобиля. Простые и мощные инструменты для управления вашим бюджетом.
Перечисление ценностных предложений (Functional Jobs) в карточках с обьяснением.

### [x] Как начать (How it Works)
Путь к идеальному порядку. Всего четыре простых шага.
Зарегистируйтесь - Фотографируйте - Анализируйте - Делитесь. (Шаг 1, Шаг 2 и т.д.)

### [ ] Почему выбирают наш сервис (Отложено / Заменено)
Перечислить эмоциональную и социальную ценность (Emotional & Social Jobs). *Частично закрыто текстами в Hero и Security.*

### [x] Безопасность и конфиденциальность данных (Security)
Банковский уровень безопасности для вашего авто. В карточках показано, как у нас хранятся данные (Yandex Cloud, S3, Приватность, Бекапы).

### [ ] Отзывы пользователей (В планах)
Блок с социальным доказательством. Пока нет реальных пользователей, можно добавить позже.

### [x] Аккордион FAQ
Частые вопросы (Как работает OCR, про данные, безопасность).

### [x] CTA (Добавлено в блок Как начать / FAQ)
Готовы начать? Присоединяйтесь к сообществу ответственных автовладельцев. Кнопка "Создать бесплатный аккаунт".

### [x] Footer
Логотип, навигация по лендингу, юридические документы, контакты техподдержки, социальные сети.
