# Анализ функций по модели Кано: "АвтоЛог"

Этот анализ помогает приоритизировать разработку, разделяя функции по их влиянию на удовлетворенность пользователя.

## 🟢 Must-be (Базовые ожидания)
*Пользователь воспринимает их как должное. Их отсутствие вызывает резкое недовольство.*
1. **Auth:** Вход через Google/Telegram.
2. **Garage:** Регистрация автомобиля (Марка, Модель, Пробег).
3. **Manual Entry:** Создание записи без фото (ручной ввод работ и цен).
4. **Basic Record Save:** Сохранение данных в БД и фото в S3.
5. **Timeline:** Простой список всех работ в обратном хронологическом порядке.

## 🔵 Performance (Линейные характеристики)
*Чем лучше реализованы эти функции, тем выше удовлетворенность.*
1. **OCR Accuracy:** Качество извлечения данных через YandexGPT (минимум ручной правки).
2. **Search & Filters:** Быстрый поиск по названию запчастей или работ в истории.
3. **Analytics Dashboard:** Наглядные графики расходов (сколько трачу в месяц/год).
4. **Processing Speed:** Скорость, с которой чек проходит путь от загрузки до верификации.

## 🌟 Attractive (Функции восторга)
*Пользователь их не ждет, но их наличие создает "Вау-эффект" и лояльность.*
1. **Bulk ZIP Upload:** Загрузка архива с историей за годы — система сама всё разложит по полочкам.
2. **"For Sale" Report:** Генерация красивого публичного отчета для покупателя в один клик.
3. **Maintenance Forecast:** Предсказание даты следующего сервиса на основе истории пробега.
4. **Demo Mode:** Интерактивная иллюстрация пользы на лендинге (до входа в ЛК).

---

## 📅 План внедрения (Stages)

### Этап 1: "Минимальный фундамент" (MVP Core)
*   Must-be функции + Базовый OCR.
*   Цель: Пользователь может зайти, добавить машину и сохранить первый чек.

### Этап 2: "Оцифровка прошлого" (The Magic Moment)
*   **Bulk ZIP Upload** + Улучшенный OCR (парсинг работ).
*   Цель: Решить проблему "10-летнего архива" одним действием.

### Этап 3: "Польза и Аналитика" (Value Extraction)
*   Таймлайн с поиском + Графики расходов.
*   Цель: Дать пользователю увидеть общую картину владения авто.

### Этап 4: "Предпродажная подготовка" (Viral Loop)
*   Генерация отчетов + Прогноз ТО.
*   Цель: Помочь пользователю выгодно продать авто или лучше планировать бюджет.
