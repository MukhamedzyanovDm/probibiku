# Frontend To-Do List: Проект "Пробибику"

Этот документ является актуальным планом разработки фронтенд-части сервиса. Он учитывает различные состояния пользователя и функциональные блоки.

## 1. Landing Page (Главная страница)
*Цель: Конверсия анонимного пользователя и быстрая навигация для авторизованного.*

### Состояния Header (Шапка):
- [ ] **Анонимный пользователь:** Кнопки "Войти" и "Добавить авто".
- [ ] **Авторизованный пользователь:** 
    - [ ] Замена кнопок "Войти/Добавить" на одну кнопку "В гараж" (к дашборду).
    - [ ] (Опционально) Аватар пользователя с выпадающим меню (Профиль, Выйти).

### Динамика блоков (для авторизованных):
- [ ] **Hero Section:** Смена текста кнопки "Добавить первый автомобиль" на "Перейти к моим авто".
- [ ] **Final CTA:** Аналогичная замена кнопок, чтобы не предлагать регистрацию повторно.

### Общие задачи по лендингу:
- [ ] **Loss Calculator (Калькулятор потерь):** Реализация логики (JS) и интерактивных полей (Марка, Возраст, Цена).
- [ ] **Report Example:** Создание визуального мока "Цифрового паспорта" (PDF или Web-вид).
- [ ] **Blog Preview:** Сетка-заглушка для будущих статей.
- [ ] **Scroll Animations:** Плавное появление секций при скролле (Framer Motion + Viewport).

---

## 2. Auth Flow (Авторизация и Регистрация)
- [ ] **Login Page:** 
    - [ ] Вход через Яндекс (OAuth).
    - [ ] Вход через Email + OTP (одноразовый код).
- [ ] **Registration Page:** Автоматическое создание профиля при первом входе.
- [ ] **OTP Verification Screen:** Экран ввода 6-значного кода из письма.
- [ ] **Onboarding (Первое авто):** 
    - [ ] Экран выбора: "Добавить авто по VIN/Госномеру" или "Ввести вручную".
    - [ ] Форма ввода: Марка, Модель, Год выпуска, Текущий пробег.

---

## 3. Dashboard: Garage (Дашборд: Гараж)
- [ ] **Empty State:** Состояние "Гараж пуст" с большой кнопкой добавления машины.
- [ ] **Car Grid:** Список карточек автомобилей:
    - [ ] Визуальный статус: "Все ок" / "Пора на ТО" / "Мало данных".
    - [ ] Быстрые действия на карточке: "Добавить чек", "Открыть историю".
- [ ] **Global Stats:** Суммарные расходы по всему гаражу (виджеты).

---

## 4. Vehicle View & Timeline (Страница автомобиля)
- [ ] **Timeline Feed:** Лента событий обслуживания:
    - [ ] Карточки событий (Дата, Пробег, Стоимость, список работ).
    - [ ] Фильтрация по годам и категориям (ТО, Ремонт, Запчасти).
- [ ] **Empty Timeline:** Состояние "Нет записей" с призывом загрузить первый чек.
- [ ] **Record Detail View:** Просмотр подробностей записи + оригинал фото чека (модальное окно).
- [ ] **Maintenance Forecast:** Виджет с прогнозом следующего визита в сервис.

---

## 5. OCR Core Loop (Оцифровка чеков)
- [ ] **Upload Interface:** Модалка загрузки (Drag-and-drop / Camera upload).
- [ ] **Processing UI:** Стилизованный лоадер ("ИИ анализирует документ...").
- [ ] **Validation & Editing Screen:** 
    - [ ] Сверка распознанных полей (Дата, СТО, Итого).
    - [ ] Редактирование позиций (Запчасти/Работы).
    - [ ] Привязка к конкретному авто из гаража.
- [ ] **Success State:** Красивая анимация завершения (Confetti/Checkmark) и переход в таймлайн.

---

- [ ] **Global Loading/Skeletons:** Скелетоны для карточек авто и записей в ленте.
- [ ] **Notifications:** Всплывающие уведомления (Toast) об успешных действиях или ошибках.
- [ ] **Mobile Optimizations:** 
    - [ ] Проверка всех форм на "наползание" клавиатуры.
    - [ ] Удобные тач-зоны для всех кнопок (уже в процессе).
- [x] **System Pages:** 404, 504, Under Construction (готово).
